# NLP Text Cleaning and Stopwords Removal App

## About the Project

This is a simple NLP (Natural Language Processing) web application built using Python and Streamlit.

It cleans raw text, converts text into lowercase, removes unwanted characters, and removes English stopwords.

## Features

* Text cleaning
* Convert text to lowercase
* Remove special characters
* Remove English stopwords
* Simple and user-friendly interface

## Technologies Used

* Python
* Streamlit
* NLTK
* Regular Expressions (re)
* Contractions

## How to Run the Project

1. Download or clone this repository.
2. Install the required libraries:

```bash
pip install streamlit nltk contractions
```

3. Run the application:

```bash
streamlit run ALL_IN_ONE.PY
```

4. Open the local URL shown in your terminal.
